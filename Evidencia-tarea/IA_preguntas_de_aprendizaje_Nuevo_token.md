Tu pregunta es muy específica: quieres saber cómo crear un tercer token (Token C), obtener su dirección, y añadirlo a la lista de Tokens Permitidos en tu DApp, utilizando tu entorno local (Anvil).Aquí te explico los pasos exactos que debes seguir.🏗️ 1. Crear y Desplegar el Nuevo Token (Token C)Para crear un Token C, necesitas desplegar una nueva instancia del contrato MockERC20.sol en tu nodo Anvil. Esto simulará la creación de un nuevo activo.A. Comando de DespliegueDe la misma manera que desplegaste TOKENA y TOKENB en el script inicial, debes ejecutar un comando similar para el Token C. Usaremos un nombre y símbolo únicos, por ejemplo, "Token C" y "TKC":Bash# Comando para desplegar el Token C
TOKENC=$(deploy_contract "Token C (MockERC20)" src/MockERC20.sol:MockERC20 --constructor-args "Token C" "TKC")
B. Obtener la DirecciónAl ejecutar este comando (usando tu herramienta de desarrollo como Foundry), la herramienta:Compilará el contrato MockERC20.sol.Desplegará una nueva instancia a tu nodo Anvil.Imprimirá la dirección del nuevo contrato en la consola y la almacenará en la variable $TOKENC.La dirección del Token C es el valor hexadecimal (0x...) que genera este proceso.2. 📋 Registrar el Token C en la DApp (Contrato Escrow)Una vez que tienes la dirección del nuevo token (por ejemplo, 0x...C367839AAf71A00a2C6A65), debes usar el módulo de Administración de tu DApp para registrarlo.A. Proceso en la Interfaz (Vista de Administración)Asegúrate de que tu billetera (por ejemplo, MetaMask) esté conectada a la red Anvil (localhost:8545).Asegúrate de que la billetera conectada sea la del Owner del contrato Escrow.sol.Ve al módulo "Añadir nuevo token" (que se muestra en la imagen).Copia y pega la dirección generada del Token C (el valor de $TOKENC) en el campo "DIRECCIÓN DEL TOKEN".Haz clic en el botón "Añadir token".B. Lo que sucede en la BlockchainAl hacer clic, la DApp ejecutará la siguiente transacción en el contrato Escrow.sol usando la función addToken:Solidity// Llamada que realiza la DApp
Escrow.addToken(direccion_del_TokenC);
Si la transacción es exitosa, el contrato Escrow registrará la dirección del Token C en su mapping allowedTokens. El Token C aparecerá inmediatamente en el "Inventario de tokens" y podrá ser usado en nuevas operaciones de Escrow.💡 Resumen: Dirección y ConstrucciónLa dirección del token no se "arma"; es generada automáticamente por la blockchain cuando el contrato MockERC20.sol se despliega.
